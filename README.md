# Suruchi Shah — Static Portfolio

A responsive, editorial-style static portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — portfolio structure/content
- `styles.css` — complete design and responsive layout
- `script.js` — tiny interaction for placeholder links
- `assets/profile.jpg` — add your profile photo here

## What to replace first

1. Add your photo at `assets/profile.jpg`.
2. Replace the LinkedIn `#` with your real LinkedIn URL.
3. Replace the GitHub `#` with your real GitHub URL.
4. Replace each project `#` with its GitHub/live/case-study URL.
5. Add detailed case-study pages or sections later.
6. Add real project screenshots later.
7. Add measurable results/metrics to the Neelcamp case study when ready.

## Run locally

Just open `index.html` in a browser.

For VS Code, the Live Server extension is convenient, but no framework or build process is required.
